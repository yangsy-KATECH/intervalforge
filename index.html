화면 잠금 전 확인

iPhone 화면을 잠그거나 다른 앱으로 이동하면 소리가 멈출 수 있습니다. 돌아오면 실제 시각으로 남은 시간과 라운드를 복원합니다. 잠금 중 구간별 효과음·알림은 보장하지 않습니다.

iPhone 설치 · 오프라인 · 사용 안내
  1. 배포된 HTTPS 주소를 Safari로 엽니다.
  2. 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’가 있으면 켜기 → 추가.
  3. 홈 화면 아이콘으로 온라인에서 한 번 실행하고 오프라인 준비 상태를 확인합니다.
  4. 효과음 테스트를 누르고 짧은 운동으로 소리를 확인합니다.
  5. 비행기 모드에서 다시 열어 오프라인 실행을 확인합니다.

Tabata 기본 4분은 마지막 10초 회복을 포함합니다. 사용자 지정 Interval은 마지막 휴식을 제외합니다. READY는 시작 전 대기이며 별도 준비 시간은 없습니다.

설정 변경은 초기화 후 가능합니다. Safari와 홈 화면 앱의 저장 공간은 별도일 수 있습니다. 사이트 데이터 삭제·저장 공간 정리·앱 제거 시 복원 데이터가 사라질 수 있습니다.

이 버전에는 예약 알림이나 Push 서버가 없습니다. 알림 권한만으로 잠금 중 타이머를 깨울 수는 없습니다.

정확한 효과음이 필요하면 앱을 전면에 두고 화면을 켜 두세요. 전화·오디오 출력 변경·무음/음량·운영체제 정책도 소리에 영향을 줄 수 있습니다.

HTTPS 또는 localhost로 열면 오프라인 파일을 준비합니다.

운동을 초기화하거나 완료한 후 적용할 수 있습니다.
